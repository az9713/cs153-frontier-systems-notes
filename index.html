Choose a reading path

Playlist path: read 1–13 below. The playlist snapshot is arranged newest first; these chapter numbers are playlist positions, not official lecture numbers.

Conceptual path: begin with 13 · Context and compute; then study 11 · Visual models, 12 · Voice, and 10 · Unified systems. Continue through 4, 6, and 7 for infrastructure; 5, 8, and 9 for building and organizations; then 1, 2, and 3 for ecosystem, scaling, and resilience.

Prerequisites: basic linear algebra, probability, derivatives, and familiarity with AI tools. Symbols are defined where introduced. For each chapter, follow a timestamp, work one numerical example by hand, and attempt the exercises before opening the solutions.

Executable companion: each chapter contains a Python example with checks. From this folder, run python labs/check_chapters.py for all thirteen, or add a chapter number to run one. The runner executes the displayed code directly using Python's standard library. These are analytical teaching models; no API keys, model downloads, or paid inference are required. See the README for files and regeneration.

How to read the evidence

The full available English transcript text was used for each recording. Ten caption sources were fetched directly from YouTube; three use explicitly identified third-party archives. Direct-caption metadata does not retain whether those tracks were manual or automatic. The archived sources describe automatic captions with light formatting.

Timestamp links locate the relevant lecture topic; they do not attribute every equation or research extension beneath the heading to the speaker. Captions do not establish continuous visual coverage: demonstrations and slides were not independently inspected frame by frame. Personal anecdotes and repetitive discussion are compressed.

These are independent study notes, not official Stanford notes. The official course site and recording playlist remain authoritative. The earliest listed recording refers to a prior class not present in this snapshot. No chapter has been invented for an unavailable recording.

Open the source map, research bibliography, and claim qualifications. Equations render offline from the bundled MathJax asset; recordings and external references require internet access.
